Global Exit Constants & Built-In Enum Tables

Standard Exit Code Constants

  • EXIT_OK (0) — Clean installation / execution success.
  • EXIT_ELEVATION_REQUIRED (740) — ERROR_ELEVATION_REQUIRED when UAC is disabled (EnableLUA = 0) for a Standard User.
  • EXIT_REBOOT_NEEDED (3010) — ERROR_SUCCESS_REBOOT_REQUIRED signaling enterprise deployment tools that a restart is pending.
  • EXIT_UNSUPPORTED_OS (9007) — Host OS build or RAM is below minimum package floor.
  • EXIT_PREREQ_MISSING (9008) — Required prerequisite runtime was declined or unavailable.
  • EXIT_DOWNLOAD_FAILED (9009) — Remote .rswpak or prerequisite download/SHA-256 verification failed.

Validation.* — Wizard Input Validation Helpers

compile.* — Build-Time Asset Embedding

compile.* calls execute at compile time during raggiescript.exe compile / pack-exe / instbuild.exe and bake the resulting JSON object or text string directly into the RSWBC2 constant pool—requiring zero external files at runtime!

MethodSignatureReturn TypeDescription
compile.jsoncompile.json(relativePath: string)anyParses a JSON file at build time and embeds the structured map/array into bytecode.
compile.textcompile.text(relativePath: string)stringReads a UTF-8 text/Markdown/RTF file at build time and embeds it as a string constant.
compile.defcompile.def(key: string, fallback?: string)stringAlias for def(key, fallback) reading -DKEY=VAL or #define.
compile.definecompile.define(key: string, fallback?: string)stringAlias for compile.def(key, fallback).
