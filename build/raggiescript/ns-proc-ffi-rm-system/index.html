proc.* & rm.* — Process Execution, Explorer De-Elevation & Restart Manager (14 Methods)

Important

Why token: Token.Desktop Matters on Finish Screens: When an elevated Setup.exe (High integrity Admin token) launches a user desktop app directly via CreateProcessW, the app inherits the Admin token—breaking Windows Explorer drag-and-drop (UIPI) and writing %LOCALAPPDATA% configs owned by Administrators! Passing token: Token.Desktop duplicates the interactive explorer.exe shell's medium-integrity token (CreateProcessWithTokenW), launching the app cleanly as the signed-in desktop user!

ffi.* — Native 64-Bit DLL Foreign Function Interface (1 Method)

ffi.call loads any native 64-bit (x64 or ARM64 matching host) DLL and marshals int/uint/ptr, UTF-8 str, and UTF-16 wstr arguments over the platform ABI (Microsoft x64 or AAPCS64 on ARM64):

MethodSignatureReturnDescription
ffi.callffi.call(dllName: string, funcName: string, returnType: string, args: array)anyreturnType: "int", "uint", "bool", "ptr", "str", "wstr", or "void". Strings inside args marshal automatically as wide UTF-16 pointers (LPCWSTR) when funcName ends with 'W', or UTF-8 (LPCSTR) otherwise!
const pid = ffi.call("kernel32.dll", "GetCurrentProcessId", "uint", []);
