CLI (raggiescript.exe), LSP, VS Code & Multi-Target SDKs

raggiescript.exe is a single zero-dependency static /MT Win32 C++20 executable compiled natively for both Windows 11 ARM64 and Windows 11 x64. It serves simultaneously as the compiler, type checker, formatter, JSON-RPC 2.0 Language Server, ES2022 transpiler, bytecode disassembler, runtime VM, and single-file .exe micro-app packager.

Soft Override (KEY=VAL) vs. IT Policy Hard-Lock (KEY:VAL)

Every param declared in a RaggieScript setup is automatically bindable from the command line without writing manual argv parsers:

# Soft Override ('='): sets initial default, but wizard UI or script logic may adjust it
Setup.exe /s installDir="D:\Apps\Workbench" createDesktopLink=false

# Hard IT Policy Lock (':'): locks the parameter immutably!
# Wizard controls bound to 'installDir' are disabled, and script reassignment fails with RSW713!
Setup.exe /s installDir:"C:\Program Files\LockedByEnterpriseIT\Workbench"
Important

Hard-locked KEY:VALUE properties are enforced by the VM runtime even if a script attempts to overwrite the variable later (RSW713), giving enterprise GPO deployments ironclad path and telemetry guarantees.

JSON-RPC 2.0 Language Server (raggiescript.exe lsp)

The built-in LSP server implements the standard Language Server Protocol over stdio with zero Node.js runtime dependencies inside the server binary:

  • initialize / shutdown / exit
  • textDocument/didOpen, textDocument/didChange, textDocument/didSave -> live textDocument/publishDiagnostics (RSW700–RSW715)
  • textDocument/completion -> context-aware dot-member IntelliSense across all 21 namespaces (fs., msi., ui., sys., user struct fields, and enum variants)
  • textDocument/hover -> Markdown signature cards, parameter counts, return types, and [Mutating] / [Read-Only] safety annotations
  • textDocument/definition -> jump-to-definition for user fn, struct, enum, and param symbols
  • textDocument/formatting -> comment-preserving whole-document formatting

Two-Way Managed .NET Host SDK (RaggieScript.Core v1.1)

RaggieSoft.RaggieScript.Core (Y:\desktop-apps\raggiescript\dotnet\src\RaggieScript.Core\) is a zero-dependency managed C# compiler, static type/capability binder (RSW700–RSW715), two-way .NET runtime, and ES2022 transpiler built for .NET desktop, CLI, and server applications (powering Accessibility Studio, Training Studio, Localization Studio, Document Studio, Launcher, Book Reader, and StoreTrainer).

2. Complete Two-Way C# <-> RaggieScript Example

using RaggieSoft.RaggieScript;

// 1. Decorate a C# service or POCO — [RsscIgnore] hides internal secrets,
//    and System.Object.GetType() is NEVER exposed to untrusted scripts!
[RsscHostObject("storetrainer", RequiredCapability = "storetrainer")]
public sealed class StoreTrainerScriptService
{
    [RsscFunction("clampSlots")]
    public int ClampSlots(int requested) => Math.Clamp(requested, 1, 10);

    [RsscFunction("saveAuditAsync", Mutating = true)] // Blocked inside wizard {} via RSW701!
    public async Task<string> SaveAuditAsync(string title, CancellationToken ct)
    {
        await Task.Delay(5, ct);
        return $"saved:{title}";
    }

    [RsscIgnore]
    public string InternalSigningSecret => "never-visible-to-scripts";
}

public sealed record AuditSummary(string Title, int Slots, Version EngineVersion);

// 2. Register C# services, async delegates, and live POCOs on RsscHostEnvironment:
var host = new RsscHostEnvironment()
    .RegisterService(new StoreTrainerScriptService())
    .RegisterGlobalFunction("toSlug", (string s) => s.Trim().ToLowerInvariant().Replace(' ', '-'));

const string rsscSource = """
    use storetrainer;
    const isPassing = (score: int) => score >= 80;

    fn upgradeProfile(name: string, requestedSlots: int): map {
        const clamped = storetrainer.clampSlots(requestedSlots);
        storetrainer.saveAuditAsync(toSlug(name));
        return { title: name, slots: clamped, engineVersion: v"1.1.0.0" };
    }
    """;

// 3. Compile with full host-aware RSW701/RSW702/RSW712 static verification:
if (RsscCompiler.Compile(rsscSource, out var program, out var diagnostics, host))
{
    var options = new RsscExecutionOptions { MaxSteps = 100_000, Timeout = TimeSpan.FromSeconds(2) };
    var runtime = new RsscManagedRuntime(program, host, options);

    // Await async C# delegates & hydrate RaggieScript map/struct straight into a C# record!
    AuditSummary? summary = await runtime.InvokeAsync<AuditSummary>(
        "upgradeProfile", cancellationToken, "Cedar Run Collector Profile", 50);

    // Or bind a RaggieScript '=>' closure directly as a native C# Func<int, bool>!
    Func<int, bool> checkScore = runtime.BindDelegate<Func<int, bool>>("isPassing");
    bool passed = checkScore(92); // true
}
