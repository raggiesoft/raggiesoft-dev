str.*, regex.*, array.*, map.*, time.*, math.*, json.*, ini.* & xml.*

Pure string, regular expression, functional array/map, ISO-8601 time, numeric math, and JSON helpers work across every RaggieScript target (C++20 VM, .NET RaggieScript.Core, and SCORM/Crossroads ES2022), while .ini and .xml file mutations participate automatically in .rsw-rollback.jnl backups!

const rawPorts = [" 443 ", " 8080 ", " 80 "];
const highPorts = array.filter(
    array.map(rawPorts, s => int(str.trim(s))),
    p => p >= 1024
); // -> [8080]
