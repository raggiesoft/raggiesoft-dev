Welcome to RaggieScript v1.0 (.rssc)

RaggieScript (v1.0.0, .rssc) is RaggieSoft's open-source (MIT License), gradually typed, capability-sandboxed curly-brace scripting language, declarative Win32 Wizard UI engine, and multi-target SDK powering all eight RaggieSoft Studio developer tools and standalone zero-dependency Windows x64 and ARM64 micro-applications.

Tip

Press Ctrl+K (or /) anywhere on raggiescript.raggiesoft.dev to search every namespace, function signature, property, and RSW700–RSW715 diagnostic instantaneously, or browse the Master A–Z API Index.

Why RaggieScript Exists

Traditional setup scripting systems force an unpleasant choice between cryptic relational database custom actions, fragile batch/PowerShell wrappers that break on locked corporate machines, or proprietary Domain-Specific Languages lacking modern types, closures, formatters, and Language Servers.

RaggieScript solves those pain points from first principles:

  1. Familiar Curly-Brace Syntax with Gradual Static Types: Write clean let / const code with automatic type inference, or annotate struct, enum, fn, path, and version (v"10.0.22000") types checked in under 1 ms (RSW710–RSW715).
  2. Compile-Time Wizard Phase Isolation (RSW701) & Commit-Time Deferred UAC: The compiler statically proves wizard { ... } cannot mutate files, Registry keys, or services—allowing uac: Uac.Deferred setups to run their entire interactive wizard un-elevated (asInvoker) and request UAC elevation only at commit time when the user clicks Install.
  3. Compile-Time Capability Sandboxing (RSW702): A script declaring use training; or use a11y; is mathematically prevented at compile time from calling fs.*, reg.*, proc.*, msi.*, ffi.*, or net.*.
  4. Automatic LIFO Transactional Rollback (.rsw-rollback.jnl): Every mutating call inside install { ... } backs up overwritten files to .rswbak and journals previous Registry/service/shortcut states before mutating, rewinding automatically if an error or user cancellation occurs.
  5. Three Verified Execution Targets from One Grammar:
  • Native Static /MT Win32 C++20 Stack VM (RSWBC2) (x64 & ARM64, zero external DLLs)
  • Managed .NET SDK (RaggieScript.Core) for Accessibility, Localization, Document, and Launcher Studio
  • CSP-Safe ES2022 JavaScript Module Transpiler (transpile-es2022) for SCORM 1.2 & 2004 courses in Training Studio

60-Second Quick Start

Create hello-setup.rssc and verify, compile, or pack it into a standalone Windows .exe:

use installer;

package "Sainte-Claire Patch Librarian" {
    id:        "RaggieSoft.SainteClaireLibrarian";
    version:   v"1.4.0";
    publisher: "RaggieSoft";
    scope:     Scope.Machine;
    uac:       Uac.Deferred;
    style:     WizardStyle.FluentMica;
}

param installDir: path = sys.programFiles / "RaggieSoft" / "Patch Librarian";
param acceptEula: bool = false;

wizard {
    step Welcome {
        ui.welcome(
            title:    "Welcome to ${product.name}",
            subtitle: "Detected Silicon: ${sys.arch()} (Windows Build ${sys.osBuild()})",
            body:     "This setup installs ${product.name} v${product.version}."
        );
    }
    step License {
        ui.license(
            text:       "MIT License — Copyright (c) 2026 RaggieSoft.",
            acceptText: "I &accept the license terms",
            bind:       ref acceptEula
        );
    }
    step Destination {
        ui.folderPicker(label: "&Destination folder:", bind: ref installDir, minFreeMB: 50);
    }
    step Ready {
        ui.readySummary(heading: "Ready to Install ${product.name}", showUacShield: !sys.isAdmin());
    }
}

install {
    ui.progress(30, "Creating installation directory...");
    fs.mkdir(installDir);
    fs.writeJson(installDir / "install-receipt.json", {
        product: product.name,
        version: product.version,
        arch:    sys.arch()
    });
    reg.writeString(Hive.HKLM, r"Software\RaggieSoft\PatchLibrarian", "InstallDir", str(installDir));
    ui.progress(100, "Installation complete.");
}

Run the standalone CLI (raggiescript.exe):

# 1. Type-check RSW701 Phase Isolation, RSW702 Sandbox & RSW710-RSW715 Types in <1 ms
raggiescript.exe check hello-setup.rssc

# 2. Format source while preserving 100% of // teaching comments
raggiescript.exe fmt --write hello-setup.rssc

# 3. Pack into a single zero-dependency native Windows .exe
raggiescript.exe pack-exe hello-setup.rssc PatchLibrarianSetup.exe
