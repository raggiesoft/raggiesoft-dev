Studio Sandbox Profiles (training.*, a11y.*, localization.*, document.*, launcher.*, help.*)

Because RaggieScript powers all eight RaggieSoft Studio tools, scripts authored for compliance, e-learning, localization, PDF generation, or help routing run inside strict compile-time capability sandboxes (RSW702).

Important

Zero Host Escape Guarantee (RSW702): Whenever a script declares use training;, use a11y;, use localization;, use document;, use storescript;, or use crossroads; (without use installer;), the RaggieScript static binder rejects at compile time any call to fs.*, reg.*, proc.*, ffi.*, rm.*, svc.*, net.*, msi.*, prereq.*, shortcut.*, shell.*, firewall.*, acl.*, task.*, env.*, arp.*, ini.*, archive.*, com.*, font.*, cert.*, sign.*, mutex.*, or activesetup.*. (For consumer profiles `storescript. and crossroads.`, see StoreScript & Story Crossroads.)

use training;

enum Outcome {
    Certify   = "slide-certificate",
    Remediate = "slide-review"
}

fn gradeAssessment(points: int, maxPoints: int) : string {
    const pct = (points * 100) / maxPoints;
    training.setScore(pct);
    training.recordObjective("OBJ-ADA-2026", pct >= 80 ? "passed" : "failed", pct);
    training.completeSlide("slide-quiz");
    return training.branchTo(match (pct >= 80) {
        true  => Outcome.Certify,
        false => Outcome.Remediate
    });
}
