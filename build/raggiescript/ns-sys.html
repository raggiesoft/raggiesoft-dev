sys.* — Silicon, OS Kernel, UAC, Known Folders & Reboot Resume

The sys.* namespace exposes true un-shimmed Windows 11 hardware, silicon, kernel, display, accessibility, and known-folder queries without ever flipping global 32-bit/64-bit state variables.

Note

Every read-only query in sys.* (40 methods + 26 properties) is 100% RSW701 Wizard-Safe. Only the 3 reboot-scheduling persistence calls (clearResumeState, scheduleResumeAfterReboot, rebootAndResume) mutate RunOnce state and require install { ... }.

CPU Silicon & Windows Kernel Version Queries

Unlike legacy installers that call GetVersionExW (which lies unless shimmed) or check PROCESSOR_ARCHITECTURE (which returns "AMD64" inside an x64 process emulated under ARM64 Prism!), sys.* calls ntdll.dll!RtlGetVersion and kernel32.dll!IsWow64Process2 directly:

sys.archsys.arch()stringRead-OnlyReturns true physical host CPU silicon: "arm64" or "x64" (pierces WOW64 & Prism emulation!).
sys.compiledArchsys.compiledArch()stringRead-OnlyReturns the compiled PE architecture of the running binary ("arm64" or "x64").
sys.isArm64sys.isArm64()boolRead-Onlytrue when physical host silicon is native ARM64 (IMAGE_FILE_MACHINE_ARM64).
sys.isX64sys.isX64()boolRead-Onlytrue when physical host silicon is x64 / AMD64 (IMAGE_FILE_MACHINE_AMD64).
sys.isEmulatedUnderPrismsys.isEmulatedUnderPrism()boolRead-Onlytrue when an x64/x86 process is running under Windows 11 ARM64 Prism translation.
sys.osBuildsys.osBuild()intRead-OnlyUn-shimmed kernel build via RtlGetVersion (22000+ = Windows 11, 26100+ = 24H2).
sys.osVersionsys.osVersion()versionRead-OnlyUn-shimmed 4-part SemVer OS version (e.g., v"10.0.26100.0").

sys.editionIdsys.editionId()stringRead-OnlyReads Windows EditionID ("Professional", "Enterprise", "Education", etc.).
