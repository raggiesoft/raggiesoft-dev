fs.* & reg.* — Transactional Filesystem & Stateless 64/32-Bit Registry

fs.* and reg.* are gated to use installer; (and use showcase; in Community/Architect editions; blocked in sandboxed profiles via RSW702). Every mutating call is 100% rollback-journaled inside install { ... } and rejected inside wizard { ... } by RSW701.

reg.* — Stateless 64-Bit & 32-Bit WOW64 Windows Registry (13 Methods)

Tip

Never toggle global SetRegView 64 / SetRegView 32 state! Every reg.* call defaults to RegView.Native64 (KEY_WOW64_64KEY) and accepts a stateless per-call view: RegView.Native64 | RegView.Wow32 | RegView.Both named argument.

let hostDir = reg.read(Hive.HKCU, r"Software\RaggieSoft\Book Reader", "Install Path")
           ?? reg.read(Hive.HKLM, r"SOFTWARE\RaggieSoft\Book Reader", "Install Path", view: RegView.Native64)
           ?? (sys.programFiles / "RaggieSoft" / "Book Reader");
