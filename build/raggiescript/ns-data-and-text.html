str.*, regex.*, array.*, json.*, ini.* & xml.*

Pure string, regular expression, functional array, and JSON helpers work across every RaggieScript target (C++20 VM, .NET RaggieScript.Core, and SCORM ES2022), while .ini and .xml file mutations participate automatically in .rsw-rollback.jnl backups!

array.* — Functional Collection Operations (4 Methods)

array.map and array.filter invoke first-class RaggieScript closures (item => ...) directly inside the linear stack VM:

MethodSignatureReturnDescription
array.pusharray.push(list: array, item: any)intAppends item and returns the new length.
array.maparray.map(list: array, transformFn: fn)arrayCalls transformFn(item) for each element and returns the mapped array.
array.filterarray.filter(list: array, predicateFn: fn)arrayKeeps elements for which predicateFn(item) returns truthy.
array.containsarray.contains(list: array, needle: any)boolStructural equality membership check.
const rawPorts = [" 443 ", " 8080 ", " 80 "];
const highPorts = array.filter(
    array.map(rawPorts, s => int(str.trim(s))),
    p => p >= 1024
); // -> [8080]

ini.* & xml.* — Configuration File Surgery (8 Methods)

Important

ini.write, ini.deleteKey, xml.replaceAttr, and xml.setElementText are marked Mutating (RSW701): they automatically snapshot the original file to .rswbak before editing so failed installations restore existing user configs byte-for-byte!
