archive.* — LZMS .rswpak & .zip Packaging (4 Methods)

RaggieSoft's .rswpak format uses Windows 11's native COMPRESS_ALGORITHM_LZMS (cabinet.dll) solid block compression paired with a 32-byte SHA-256 integrity header:

MethodSignatureReturnMutating?Description
archive.extractZiparchive.extractZip(zipFile: path, destDir: path)intMutating (RSW701)Extracts a standard .zip archive into destDir (rollback-tracked), returning file count.
archive.createPakarchive.createPak(sourceDir: path, outPakFile: path)stringMutating (RSW701)Compresses sourceDir into an LZMS .rswpak container and returns its 64-char hex SHA-256 digest.
archive.extractPakarchive.extractPak(pakFile: path, destDir: path, expectedSha256?: string)intMutating (RSW701)Verifies optional expectedSha256 + internal RSWPAK1 digest and extracts files into destDir.
archive.downloadPakarchive.downloadPak(httpsUrl: string, destDir: path, expectedSha256?: string, verifyAuthenticode?: bool)intMutating (RSW701)Streams a remote on-demand feature pack over TLS 1.2/1.3 WinHTTP, verifies SHA-256 BEFORE unpacking, and extracts into destDir.

crypto.* — CNG bcrypt.dll Hashing, UUIDv5 & Authenticode (7 Methods)

All crypto.* methods are 100% Read-Only & Wizard-Safe, implemented directly against Windows bcrypt.dll and wintrust.dll with zero OpenSSL DLL dependencies:

MethodSignatureReturnDescription
crypto.sha256crypto.sha256(text: string)stringComputes lowercase 64-char hex SHA-256 of UTF-8 text.
crypto.sha256Textcrypto.sha256Text(text: string)stringExplicit alias for crypto.sha256(text).
crypto.sha256Filecrypto.sha256File(file: path)stringStreams file in 64 KB chunks through BCRYPT_SHA256_ALGORITHM and returns 64-char hex SHA-256.
crypto.crc32Textcrypto.crc32Text(text: string)intComputes unsigned IEEE 802.3 CRC-32 checksum of text.
crypto.newGuidcrypto.newGuid()stringGenerates a random uppercase {GUID} via BCryptGenRandom.
crypto.uuid5crypto.uuid5(name: string, namespaceGuid?: string)stringGenerates deterministic RFC 4122 SHA-1 UUIDv5 {GUID} for reproducible MSI Component GUIDs.
crypto.verifyAuthenticodecrypto.verifyAuthenticode(peFile: path)boolVerifies Microsoft Authenticode / Azure Artifact Signing chain via WinVerifyTrust.

net.* — Native TLS 1.2 / 1.3 WinHTTP Client (4 Methods)

net.* uses the OS-integrated winhttp.dll stack (automatically honoring enterprise Windows proxy auto-config / WPAD and OS certificate stores) and requires use installer; (RSW702 blocked in sandboxed profiles):

MethodSignatureReturnDescription
net.downloadnet.download(httpsUrl: string, destFile: path, expectedSha256?: string)boolDownloads httpsUrl to destFile with live UI progress; deletes destFile and returns false if expectedSha256 mismatches!
net.getTextnet.getText(httpsUrl: string)stringPerforms an HTTPS GET and returns the UTF-8 response body.
net.getJsonnet.getJson(httpsUrl: string)anyFetches and parses a remote HTTPS JSON manifest (catalog.json, release channels, etc.).
net.probenet.probe(httpsUrl: string)boolPerforms a fast 4-second HEAD/GET reachability probe (true on HTTP 200..299).
