archive.* — Zero-Dependency Multi-Format Packaging & Extraction (23 Methods)

Every archive.* function in both raggiescript.exe (static /MT Win32 C++20) and RaggieScript.Core (.NET v1.2) runs against 100% EULA-clean, zero-dependency engines built straight into Windows 11 (x64 & ARM64):

  • System32\cabinet.dll (COMPRESS_ALGORITHM_LZMS) + bcrypt.dll (SHA-256): Powers RaggieSoft's solid .rswpak (RSWPAK1) container in-process with 100% binary wire compatibility between C++20 and .NET.
  • System32\tar.exe (bsdtar 3.8.9 / BSD libarchive + zlib + Public-Domain liblzma 5.8.3 + bz2lib + libzstd 1.5.7): Powers .zip (plus .nupkg, .vsix, .epub, .msix), .7z (LZMA / LZMA2 solid), .tar (.tar.gz, .tar.bz2, .tar.xz, .tar.lzma, .tar.zst), .zst (Zstandard bundles), .iso (ISO 9660 Collector's Edition optical disc images for Showcase Studio), .cpio, and .xar.
  • System32\makecab.exe (LZX:21 multi-folder .ddf): Builds genuine Windows .cab cabinets for .msi media and driver packages.
  • System32\wimgapi.dll (WIMCreateFile / WIMCaptureImage / WIMApplyImage): Captures and applies Windows .wim images when elevated (Uac.Deferred / Uac.RequireAdministrator), automatically enabling SeBackupPrivilege and SeRestorePrivilege.
Important

Security, Transactional Rollback & EULA Guardrails:

1. Pre-Extraction Zip-Slip (../) Gate: Every entry is audited before extraction; any .. traversal segment, rooted path, or drive prefix aborts immediately before touching disk.

2. Automatic .rsw-rollback.jnl Undo: Every archive.extract* call unpacks into an isolated staging directory first and commits files through the LIFO rollback ledger—backing up overwritten destination files to .rswbak!

3. Permanent .rar Exclusion: Proprietary .rar archives (Rar! magic or .rar extension) are permanently rejected so RaggieScript never touches RARLAB/unRAR license restrictions.

use installer;

param payload7z: path = sys.supportDir / "StarlightAssets.7z";
param installDir: path = sys.programFiles / "Starlight";

wizard {
    step VerifyMedia {
        // archive.verify() and archive.list() are 100% read-only & allowed inside wizard {}!
        if (!archive.verify(payload7z)) {
            ui.notice("Collector media archive is missing or corrupted.");
        }
    }
}

install {
    // Automatically journaled in .rsw-rollback.jnl — rolled back cleanly if a later step fails!
    const extracted = archive.extract7z(payload7z, installDir / "Assets");
    const backupSha = archive.createZst(installDir / "Config", sys.localAppData / "Starlight" / "config-backup.tar.zst");
    log.info("Unpacked ${extracted} files; config snapshot SHA-256 = ${backupSha}");
}
