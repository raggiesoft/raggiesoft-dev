storescript.* (StoreTrainer) & crossroads.* (Story Crossroads)

RaggieScript v1.3 brings first-class, RSW702 capability-sandboxed domain profiles to two flagship RaggieSoft consumer experiences: StoreScript (use storescript;) for RaggieSoft StoreTrainer, and Story Crossroads (use crossroads;) for interactive branching novels in RaggieSoft Book Reader and https://crossroads.raggiesoft.com.

Important

Zero OS Escape Guarantee (RSW702): Both use storescript; and use crossroads; are strictly sandboxed at compile time. Neither profile can call fs.*, reg.*, proc.*, ffi.*, net.*, msi.*, svc.*, com.*, or archive.*—meaning community trainer scripts and interactive fiction modules are 100% safe to share, inspect, and execute offline without antivirus false positives or host filesystem risk.

storescript.* — StoreScript Save-File & Config Trainer DSL (20 Methods)

Origin Story: Hello, StoreScript!

Long before RaggieScript unified all eight RaggieSoft Studio developer tools, Michael P. Ragsdale envisioned StoreScript as a dedicated scripting language for RaggieSoft StoreTrainer (storetrainer.raggiesoft.com—originally created in the pre-AI Visual Basic 6.0 TStore.vbp era as an offline single-player PC game save-file and trainer utility).

In RaggieScript v1.3, StoreScript is officially part of RaggieScript:

  • The host application (StoreTrainer on .NET via RsscManagedRuntime.StoreScript or C++20 via RaggieScriptVm::LoadStoreScriptBuffer) loads only the single save file or JSON configuration explicitly selected by the user into an isolated in-memory workspace.
  • StoreScript provides automatic undo snapshots (storescript.backupSave / restoreBackup), wildcard hex-signature scanning ("43 52 45 44 ?? ??"), bounds-checked and min/max-clamped little-endian binary reads/writes (U8, I16LE, I32LE, F32LE, Ascii), IEEE 802.3 CRC-32 save-checksum recalculation (crc32Range), and dot-path JSON config editing (getJson / setJson).

use storescript;

const meta = storescript.profile("cedar-run-tactics", "Cedar Run Tactics — Save Utility", "*.sav");

fn applyCreditsBoost(requestedCredits: int) : map {
    const snap = storescript.backupSave("pre-credits");
    const sigOffset = storescript.findPatternHex("43 52 45 44 ?? ??");
    if (sigOffset < 0) {
        return { ok: false, reason: "Signature not found" };
    }

    // Write clamped 32-bit little-endian credits right after the 6-byte header
    storescript.writeI32LE(sigOffset + 6, requestedCredits, min: 0, max: 999999);

    // Recompute IEEE CRC-32 over payload bytes [4..size) and store at offset 0
    const crc = storescript.crc32Range(4, storescript.size() - 4);
    storescript.writeU32LE(0, crc);
    return { ok: true, backupId: snap, newCredits: storescript.readI32LE(sigOffset + 6), crc32: crc };
}

crossroads.* — RaggieSoft Story Crossroads Interactive Novel Engine (8 Methods)

RaggieSoft Story Crossroads (crossroads.raggiesoft.com, in-universe Architects: Rowan & Iris Hawthorne) is RaggieSoft's independent interactive-fiction imprint. A single use crossroads; .rssc file executes natively inside RaggieSoft Book Reader (.NET) and compiles via raggiescript.exe transpile-es2022 (or RsscEs2022Transpiler.TryTranspile) into a zero-eval() ES2022 JavaScript module for the web!

use crossroads;

fn evaluateKeystoneBridgeScene(hasLanternKey: bool) : array {
    const visits = crossroads.visit("cpi-keystone-bridge-dusk");
    if (hasLanternKey) {
        crossroads.setFlag("unlockedArchivistVault", true);
    }
    crossroads.offerOption(
        "Inspect the Ironstone keystone inscription with Iris",
        "cpi-pendleton-archive",
        true,
        visits > 1 ? "Revisit with new clues" : "First inspection"
    );
    crossroads.offerOption(
        "Unlock the lower Commonwealth Mall lantern passage",
        "cpi-lantern-vault",
        crossroads.getFlag("unlockedArchivistVault", false) == true,
        "Requires the Archivist's brass lantern key"
    );
    return crossroads.options();
}
