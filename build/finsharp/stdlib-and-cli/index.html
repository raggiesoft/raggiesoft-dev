finsc CLI, Standard Library & .NET Compiler Architecture

Fin# (FinSharp.Compiler / finsc) is architected as a clean, fast, 100%-readable self-hosted C# compiler frontend ("Mini-Roslyn" design) targeting .NET 10 / 11 CoreCLR and NativeAOT—interoperating seamlessly with every .NET NuGet library while keeping build times under 3 seconds.

finsc Command-Line Interface Reference

CommandFlags & ArgumentsPurpose
`finsc check <file\dir>`--diagnostics=json, --strictRuns Lexer -> Parser -> Binder -> LinearFlowAnalyzer (FIN0001–FIN0005) in milliseconds without writing binaries.
finsc build <project.finproj>-o <dir>, --aot, --pdbVerifies all conservation proofs and lowers verified syntax trees via Microsoft.CodeAnalysis.CSharp (Roslyn) into deterministic .dll / .exe assemblies.
finsc audit <ledger.fin>--standard=Z_SOX_302, --jsonExecutes ledger transactions deterministically and emits a SHA-256 Merkle trial-balance attestation report.
`finsc fmt <file\dir>`--write, --checkComment-preserving source formatter that aligns account, debit, and credit columns cleanly.
finsc lsp--stdioLaunches the JSON-RPC 2.0 Language Server providing real-time red squiggles for FIN0001–FIN0005 and live T-account hover cards.

Function SignatureReturn TypeDescription
capital.splitEqual(amount: Capital<T>, ways: Int32, policy: RoundingPolicy)(Capital<T>[], Capital<T>)Consumes amount and returns ways equal shares plus an explicit linear remainder so zero sub-cents ever vanish (FIN0005).
capital.allocateByWeights(amount: Capital<T>, weights: Int64[])Capital<T>[]Consumes amount using deterministic Largest-Remainder (Hamilton) allocation guaranteed to sum to amount with zero leftover cents.
capital.combine(left: Capital<T>, right: Capital<T>)Capital<T>Consumes two same-currency bindings (FIN0004 checked) and returns their exact 128-bit fixed-point sum.
capital.assertZero(value: Capital<T>)UnitSafely consumes a linear binding proven to equal 0.00 (for example, an exhausted loop accumulator). Traps in audit mode if non-zero.

fx.convert(source: Capital<TFrom>, quote: Rate<TFrom, TTo>, bridge: FxBridge<TFrom, TTo>)(Capital<TTo>, FxAuditReceipt)Consumes source into bridge's TFrom clearing leg and sources balanced Capital<TTo> from bridge's TTo leg.

Compiler Pipeline Architecture ("Mini-Roslyn" on .NET)

Why build FinSharp.Compiler as a standalone immutable C# syntax tree lowering to Roslyn rather than forking all 4+ million lines of dotnet/roslyn?

  1. Sub-3-Second Cold Builds: Developers and contributors can clone, read, and compile the entire Fin# toolchain in seconds without a 30 GB compiler build environment.
  2. 100-Level Read-Along Clarity: Every pass—FinLexer -> FinParser -> FinBinder -> LinearFlowAnalyzer -> CSharpRoslynEmitter—fits cleanly in well-commented C# files.
  3. Full .NET & Studio Ecosystem Integration: Emits standard signed .NET IL + PDBs and powers a candidate RaggieSoft Fin# / Ledger Studio workstation (WebView2 + Monaco + Live T-Account Visualizer, honoring Community == 100% Architect Feature Parity!).
